FV SNAPSHOT + TD RECONSTRUCTION

Output: FV_CCTV_snapshot_TD_reconstruction.mp4
Source packets: PKT-CCTV-001, PKT-CCTV-002, PKT-CCTV-003

Construction method
- Uses preserved snapshot images listed in each packet's snapshot manifest; Part 3 uses its preserved whole-second verification snapshots.
- Displays snapshots sequentially with packet-local source timestamps and the applicable TD interval/observation.
- Preserves the three packet timebases as separate sections; no claim is made that the packet boundaries are continuous source chronology.
- No motion interpolation, object tracking, identity inference, or synthetic in-between frames are added.
- Playback holds each selected snapshot for one display second. This display cadence is not source-time cadence. Source time is printed on every frame.
- Audio is omitted.

Interpretation
This is a snapshot/TD reconstruction for review, not a recovered continuous CCTV recording and not a validated/compiled FV packet. It visualizes the evidence currently preserved in the packets and their TD records.

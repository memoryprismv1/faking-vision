Load a video and an FV JSON packet to begin.

1 · Load source

IDs are read from the loaded packet; no new object IDs are invented.

2 · Viewpoint object (VPO)

Camera pose is separate from source viewpoint provenance and scene/object inventory. Default frame: right-handed, +X right, +Y up, +Z toward viewer; camera forward is −Z. Position units are scene units.

This MVP stores and validates the portable camera instruction. It does not reconstruct missing 3D geometry or re-render a 2D source image from a new physical camera position.

3 · Edit object property

The property is written into matching object records and logged. The visual colour edit is rendered only inside the hand-drawn mask.

4 · Shape keyframes

Draw a polygon on the frame and save it at several times as the object moves. Same-vertex-count shapes are interpolated between saved times. This is manual mask tracking, not automatic AI segmentation.

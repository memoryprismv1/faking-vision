Purpose
-------
Desk/display-area scene with a tabletop, visible objects, shelving/cabinet structure, windows, plants, and foreground furniture.

Packet scope
------------
This packet records semantic entities and supported spatial relationships visible in the source image. It does not treat scene category knowledge as permission to add conventional objects. Exact coordinates are not encoded where the image supports only relative placement.

Files
-----
OI.json   Object/instance inventory
MSRM.json Spatial organization and relationships

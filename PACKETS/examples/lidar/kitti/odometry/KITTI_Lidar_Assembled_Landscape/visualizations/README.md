# Packet visualizations

These visual assets are placed with the packet they illustrate. They are not substitutes for source sensor data, exposures, frame evidence, or machine-readable reconstruction artifacts.

The images are supplied/generated visualizations. Numerical labels and depicted outcomes are not independently verified merely by inclusion in this folder.

## Making Vision- Version 1

I was just looking how to deal with my personal unhappiness with AI image analysis. A bare basics project guidelines so that AI can do a better job analysing an image without prompt. My personal experiences, phone games (honourable mention to June's journey and Happy Colors-art section) and object oriented architecture created the base. Science verification was done much later when more than half the work was done. Gap testing using Claude, Gemini and Grok while main chat was using Chatgpt.

Vision is often described as though its primary task were to turn photons into recognized objects.

That is too narrow.

An organism does not encounter the world as an empty visual field waiting to be labelled. It already possesses persistent knowledge, spatial maps, object and material knowledge, expectations, learned behaviours, inherited information, social information, and current needs. Vision enters that already- functioning system and supplies current information to it.

But vision is not merely an API into a database either. A genuinely unfamiliar environment can still be navigated. A novel surface can still be matched. Moving neighbours can still be tracked. Free space can still be extracted. Current visual structure can be useful before the organism knows what the thing is.

Making Vision therefore treats biological vision as a high-bandwidth system for extracting structured information from current visual input and integrating that information with an organism's existing knowledge, spatial machinery, expectations, state, and action systems.

The central problem is not:
- How does vision recognize everything?
- It is:
- How does an organism decide what current visual information matters, what it already knows

about it, what it can infer directly from the current input, and what deserves further processing or persistence?

## Object knowledge is individual

Two members of the same species do not necessarily possess the same object/material database.

A wiper is a good example.

- For another:
- wiper → unfamiliar strange thing → uncertainty → caution.

- same species + different developmental boards → different persistent object knowledge →

different future promotion and behaviour.

Object familiarity is therefore not merely an objective property of the object.

It is partly a property of the relationship between object and organism.

## Sensory information is not equally processed

The organism cannot deeply process everything.

There is a broad, cheap sampling process:
- lazy scan
- Most environmental information can remain cheap. A familiar room contains enormous amounts of

information that simply does not deserve active processing every moment.

The organism can rely on:
- existing map
- existing expectations
- existing object knowledge
- existing routines
- and let most of the board remain in the background.

This is one of the major efficiencies of biological perception.

## Managed expectations

The organism does not merely see:
- everything that is physically present.

It maintains expectations about the current board.

Examples:
- a dining table has certain things on it
- a doorway has open passage
- a switchboard contains familiar switches
- a road contains vehicles behaving within ordinary patterns.
- Most expected information therefore requires little active attention. This creates an enormous

efficiency gain.

A familiar chair in its familiar location does not repeatedly demand:
- “WHAT IS THAT?”
- The organism already knows.

## Perturbation

A perturbation is information that escapes the cheap background treatment and becomes potentially worth further processing.

It can be:
- unexpected movement
- unexpected location
- missing expected object
- unusual object
- unusual behaviour
- unusual relationship
- relevant sensory event
- internally generated sensory anomaly.
- But:
- not every perturbation gets promoted.
- This is important.

A change can be noticed without becoming important.

A look-see can happen without resulting in durable memory.

A board can contain thousands of tiny changes that never become meaningful.

## Object promotion

The critical transition is:
- background → candidate → promoted object/event
- Object promotion means:
- this is now worth processing.
- It does not necessarily mean:
- “I know exactly what this is.”
- Promotion can precede classification. This distinction becomes especially clear in novel

environments.

An animal can approach an unfamiliar object because it has judged:
- worth investigating.
- The object may not yet have a name, identity or complete classification.

Promotion is therefore an allocation of processing and behavioural resources, not necessarily a finished perceptual verdict.

## Promotion is state-dependent

Novelty alone does not determine promotion. The same novel object can produce different behaviour depending on the organism's state.

A child may explore a novel toy when:
- secure
- regulated
- comfortable
- mentally available.
- The same child may prefer a familiar object when:
- uncertain
- unsettled
- seeking reassurance.
- Thus:
- novelty ≠ automatic promotion.
- Promotion depends on something closer to:
- current state × existing knowledge × current board × current needs/constraints

The current state matters because the organism's priorities change with time. A hungry predator and a satiated predator can encounter the same stimulus and allocate attention differently.

A safe, relaxed organism can afford exploration. An organism under threat may have no interest in exploratory information.

An organism that needs reassurance may actively choose the familiar over the novel.

## Exploration is an expenditure

Exploration is not free.

To investigate something, an organism may have to spend:

- time
- attention

exposure

motor effort

risk tolerance.

Therefore an organism's exploration behaviour reflects not merely:
- “what is interesting?”
- but:
- “what is worth spending resources on right now?”
- This makes the first approach to a novel object ecologically informative.

If an animal enters an unfamiliar environment and chooses to approach one object rather than another, that behaviour potentially reveals something about:
- its existing danger knowledge
- material familiarity
- affordance knowledge
- current need
- current state
- exploration threshold.

An organism can encounter:

## The first explorer changes the experiment

When a new object enters a social environment, the first animal to interact with it can change what everyone else knows.

## Persistence is selective

Promotion does not automatically create persistent knowledge.

An organism can:

## Persistence depends on relevance and attachment

Some information becomes durable because it is repeatedly useful. Some becomes durable because it is strongly attached to a location.

A tiny object with strong attachment can persist. A large temporary object can disappear from memory quickly.

## Camouflage: avoiding promotion

Camouflage provides an unusually clean demonstration of object promotion. The camouflaged organism is not necessarily trying to make the predator identify it as another animal.

Often the desired outcome is much simpler:
- I am background.
- The organism wants to remain:
- scenery
- surface
- stationary structure
- environmental texture
- background noise.
- In other words:
- Don't see me.
- Or more precisely:
- Don't promote me.
- The organism is trying to avoid becoming the perturbation that causes the observer to allocate

further processing.

## Camouflage is not necessarily “pretending to be another species”

This distinction matters.

A leaf insect does not need to convince a predator:
- “I am definitely Species X.”
- It can be enough to maintain:
- “nothing here is an actionable animal.”
- Appearance matters.
- Behaviour matters.
- Movement matters.
- Expected background behaviour matters.
- A creature that visually resembles a leaf but suddenly moves like an animal may generate exactly the

perturbation that defeats the camouflage.

Thus camouflage exploits the observer's existing machinery:
- background expectation → candidate detection → promotion
- by trying to remain on the background side of the boundary.

This is the cleanest sense in which camouflage is faking vision:
- “I need to project that I am part of the scenery.”

## Camouflage is conditional

Camouflage-capable organisms do not necessarily maintain maximal camouflage constantly.

The behaviour is state-and need-dependent.

The organism can remain in an ordinary state until:

Then:
- current sensory input → processing → skin/body state change.
- This is another example of:
- capability existing continuously while its expensive deployment is conditional.

## The simplest statement of Making Vision

A biological visual system does not need to deeply understand everything it sees.

It needs to:
- 1. Acquire current visual structure.
- 2. Use existing knowledge where available.
- 3. Maintain expectations about the current board.
- 4. Cheaply scan most of the environment.
- 5. Detect candidate perturbations.
- 6. Promote some candidates for deeper processing.
- 7. Use current state and needs to determine what deserves that promotion.

8. Extract useful structure even when no prior object knowledge exists.

9. Feed current information into spatial, motor and other sensory systems.

10. Persist sufficiently meaningful discoveries into existing knowledge and maps.

11. Allow future perception to be altered by what has been learned.

The result is neither a camera nor a database.

It is a selective, state-dependent interface between current visual structure and a persistent organismic system.

## The particularly useful insight

The strongest insight to carry forward is perhaps this:
- Being physically present is not the same as becoming perceptually important.

A chair can occupy the visual field without becoming an object of active processing.A camouflaged animal can be physically present without becoming an actionable object. A spilled patch of water can become highly important because it interrupts an expected walking path.

A familiar object can become a task reminder because a person deliberately places it where future foot traffic will promote it. A novel object can become worth exploring because the organism's current state makes investigation affordable.

The organism therefore does not merely perceive objects.

It continuously decides, through the interaction of sensory input, expectations, knowledge and current state:
- what deserves to become an object of attention and action.

That is the core problem Making Vision is trying to explain.

Purpose
-------
Example FV packet for a single still image. The packet records the visible reconstruction target using OI + MSRM. No project constants are required.

Analysis scope
--------------
The packet records semantic entities and spatial relationships supported by the supplied image. Appearance details that are not separately useful semantic entities remain properties/appearance rather than becoming additional objects.

Important reconstruction rule
-----------------------------
The packet is a closed semantic inventory. Do not add objects or components because they are conventional for a bedroom or because the renderer considers them useful.

Files
-----
OI.json   Object/instance inventory
MSRM.json Spatial organization and relationships

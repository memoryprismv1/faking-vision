# Environmental edits

This directory groups environmental-edit examples separately from the legacy image/video packet families. Image examples belong under `images/`; future video examples can be added under `videos/`.

## Current examples

- [Seine at Giverny — seasonal and time-of-day edits](images/seine_giverny/): source packet records, four edit variants (image assets to be added separately), and independent audit notes.

The packet's original reports are preserved as producer-supplied records. See the nested audit notes for independent observations and limitations.

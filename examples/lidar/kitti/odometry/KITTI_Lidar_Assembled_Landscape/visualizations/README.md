# Packet visualizations

These visual assets are placed with the packet they illustrate. They are not substitutes for source sensor data, exposures, frame evidence, or machine-readable reconstruction artifacts.

The images are supplied/generated visualizations. Numerical labels and depicted outcomes are not independently verified merely by inclusion in this folder.

## Files present in this folder

- `11_kitti_sequence00_assembled_map.jpg` — KITTI Sequence 00 assembled-map illustration.
- `12_kitti_sequence00_assembled_map_duplicate.jpg` — Second supplied version of the Sequence 00 map; retained because its bytes differ from the first file. This is a distinct file version, not a verified independent assembly result.
- `13_additional_lidar_visualization.jpg` — Additional supplied LiDAR visualization; exact packet association unspecified.
- `14_additional_lidar_visualization.webp` — Additional supplied LiDAR visualization; exact packet association unspecified.

Earlier catalogue labels `08_kitti_lidar_craft_poster.jpg` and `09_lidar_city_scene.png` are not present in the current folder and are not listed as available assets here.

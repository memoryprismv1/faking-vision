Purpose
-------
Example FV packet for a single still image. The packet records the visible reconstruction target using OI + MSRM. No project constants are required.

Analysis scope
--------------
The packet records semantic entities and spatial relationships supported by the supplied image. Appearance details that are not separately useful semantic entities remain properties/appearance rather than becoming additional objects.

Important reconstruction rule
-----------------------------
The packet is a closed semantic inventory. Do not add objects or components because they are conventional for a bedroom or because the renderer considers them useful.

Files
-----
OI.json   Object/instance inventory
MSRM.json Spatial organization and relationships


DISPUTES: NONE

LEGACY METADATA BOUNDARY
This is a legacy v0.24 image-analysis packet. It contains OI/MSRM and the source image, but no root-level `viewpoint.json` or `packet_provenance.json`. The README's source-page/creator/licence notes are descriptive attribution, not a structured provenance record. Source camera position, orientation and calibration are not established. The virtual `VP-DEFAULT` is read-time compatibility only; it is not a render VPO and supplies no camera pose. Do not synthesize missing source geometry or provenance. This packet is not prompt-compilation ready without a separately declared render VPO. The missing structured provenance record remains a documented legacy limitation; do not invent it.
